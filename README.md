# LEaPReg — Local Elites Across Political Regimes

Research website for the LEaPReg project, investigating the architecture of local political power in Spain from Francoism to democracy (1939–1983).

Live site: [www.leapreg-project.org](https://www.leapreg-project.org)

## About

LEaPReg reconstructs the machinery of local power during the Francoist Dictatorship (1939–1976) and examines the democratic Transition (1976–1983) to understand how local elites survived regime change. The project combines historical archival research with Artificial Intelligence tools to build the most comprehensive database on Spanish historical municipal power to date.

## Stack

Static site — HTML, CSS, vanilla JS. Hosted on GitHub Pages.
